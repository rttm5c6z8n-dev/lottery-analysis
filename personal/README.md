# B＋C个人研究版

第二阶段已将历史训练、滚动重放回测与模拟研究独立开放；详见[第二阶段流程与证据边界](STAGE2.md)。下文为第一阶段正式预测机制，仍保留；“没有官方计划不能生成”仅指正式预测，不限制第二阶段模拟。

## 来源与当前限制

服务端 `/api/research-latest` 只访问江苏体彩公开列表第一页与其最新一期原公告：

- `https://api.js-lottery.com/Lottery/_ListData?itemType=lo&pageindex=1`
- 目前原公告 `https://api.js-lottery.com/cms/post-148224.html`，26128，正文开奖日期2026-11-09，03 13 20 25 34 + 09 12。

列表发布日期不充当开奖日期，复用既有严格原公告解析器。返回来源、标题、原文文本、发布日期、实际开奖日期、号码与获取时间。HTTP非200、重定向、格式变化、超时均停止；没有验证码绕过或任意URL代理。官方访问失败不视缓存为实时。

该公开源没有提供可证实的下一期期号、日期、开售及停售计划，API始终明确返回 `next:null`，页面默认“待确认”，不按日历推算。支持用户实际阅读官方原文后录入完整计划并确认；录入会被明确标为人工摘录。不得编造摘录以解锁生成。休市禁止生成；日期变动需新证据，缺乏明确延期/调整说明时标为冲突。计划时间到只表示计划已到，不能证明实际已开奖。官网完整计划缺失时，正式生成目前不可用，这是数据限制，不能宣称已自动取得下一期。

北京时间用 `Asia/Shanghai` 显示，所有人工时间必须显式带 `+08:00`，拒绝无时区、无效日历日期。官方原始时间戳保留UTC来源格式，显示时统一转换北京时间。页面进入、恢复可见时检查最近公告；每分钟更新状态，距计划开奖30分钟内每分钟读取一次，非实时销售接口。最近成功检查和人工目标确认均在5分钟内且仍在销售期才允许生成。

## 数据与不可覆盖约束

只读一次原键 `lottery_v2_dlt`，不写任何旧localStorage、旧IndexedDB。所有新增内容在独立 `lottery_personal_bc` v1：

- `events`：只追加官方检查、失败、人工目标依据、事务锁定确认。
- `data`：只追加本次原历史快照、读取时间、SHA256；每条可用时间保守设为实际读取时间，不追溯回填。
- `predictions`：以目标期号唯一 `add`，不使用 `put/delete/clear`。包含目标、生成截止时间、数据哈希、实际训练200条、随机种子、版本、5组号码及分项评分、当时评估状态。
- `backtests`：追加严格时间可用性回测报告。
- `assessments`：按期号唯一追加开奖后评分；官方新结果不改原预测。

IndexedDB事务完成才报告成功；存储失败显示错误。保存确认若晚于停售/计划开奖，或缺少独立成功锁定事件，不计前瞻成绩。无IndexedDB时阻止生成。模块不是抗用户篡改的第三方公证服务，设备时钟和用户提供证据的真实性仍需人工保证。

同一期重复、日期/年份异常、未来可用时间、目标及以后期号均排除；日期保守取当日23:59:59之后才可训练。最新官方公告若与读取历史缺失/重复/日期或号码冲突，阻止生成，不修复原缓存。现有历史数量完全读取自设备，不硬编码2946，也不初始化历史。

## 策略和评估

版本 `BC-ensemble-1.0`：固定200条窗口，至少120条合格样本，1500个可复现随机候选，频率25%、冷热遗漏20%、结构20%、近期频率变化20%、频率异常稳健性15%加权，选5个唯一组合。各评分为启发式指标，不是已证实的开奖规律或训练好的概率模型。第一组只表示候选融合分最高。没有人为干预假设或提升中奖概率的宣称。

每组显示分项、综合分、模型版本与该排名的历史完整5+2命中/有效回测折数。旧缓存没有可信 `predictionCutoff` 和历史 `availableAt`，故真实历史样本外成绩显示“未执行/无可核实折数”，不能将缺失成绩填为0命中。回测仅对有完整时间证据的折使用截止前数据，目标及以后数据不能进入训练，参数固定、不用测试折调参；这仍不是策略有效性的统计确认。开奖后前瞻评分与旧回测分开保存，以完整5+2为主，部分命中仅辅助。JSON导出包含所有本模块证据/快照/评分。

## 测试与操作

先在 `/personal/` 检查官方公告；如果有真实完整下一期官方计划，人工摘录核实。点击只读历史快照，再生成；无完整目标或网络过期时不能生成。刷新后恢复研究库；同一期不能再次生成覆盖。开奖结果公布后先重新读取官方公告，再追加评分。可导出完整研究JSON存档。

执行：

```
node tests/personal.test.cjs
node tests/personal-source.test.mjs
# 在项目目录运行本地静态服务 localhost:8000 后：
node tests/personal.browser.cjs
node tests/personal-nav.cjs
```

核心测试和浏览器测试使用 `/tmp/v27-third-party.json` 历史下载样本；来源测试使用 `/tmp/v29-js-data.html`、`/tmp/special-26128.html` 保存的官方原文。浏览器隔离测试追加真实26128构成2946条样本，并使用**明确模拟、只在测试环境**的下一期完整计划验证正常生成；它不表示生产已有下一期官方计划。测试不连接用户设备，不代表迁移/操作过用户设备数据。

覆盖：北京时间跨年/无效日期、休市/延期冲突/销售截止/公告延迟、重复与未来数据过滤、5组唯一排序、无时间证据不伪造回测、测试合成时间证据的严格留出、同一期不可覆盖、离线阻止、真实事务中断、不支持IndexedDB、JSON导出、刷新保持快照、旧存储写保护、390px移动布局与导航。另跑既有V27/V28/V29核心、审计、采集和断点回归。Chromium移动视口不等同真实iPhone Safari；当前环境没有WebKit运行时，需设备验收。
